A program that writes one weird job title — "Professional Tooth Fairy Auditor" (32 characters) — to `/output/entry.txt` and nothing else. Entered on make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty, where a blind AI judge compares titles two at a time and picks the weirder, funnier one.

The title was chosen by blind-testing 10 candidates with a free model against the judge's published criteria (weird, stranger than ordinary work, funny on first read, sounds like a real job, reads instantly), then checking the public web for exact-phrase duplicates (the blind-round feed hides all entry texts, so no feed check was possible). The Tooth Fairy as a stern auditor — a bureaucratic twist on a childhood myth — is absurd, specific, and instantly pictureable. It won the blind test head-to-head against the runner-up, "Chief Snail Racing Referee", in both orders; the blind test used a free proxy model, so that result is directional, not a guarantee against the real judge.

## Run it

```sh
node main.ts
```
