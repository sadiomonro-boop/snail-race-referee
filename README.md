A program that writes one weird job title — "Chief Snail Racing Referee" (26 characters) — to `/output/entry.txt` and nothing else. Entered on make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty, where a blind AI judge compares titles two at a time and picks the weirder, funnier one.

The title was chosen by blind-testing 10 candidates with a free model against the judge's published criteria (weird, stranger than ordinary work, funny on first read, sounds like a real job, reads instantly), then checking the public feed for duplicates. Snail racing is a real, gloriously slow sport — so a chief referee for it is absurd, specific, and instantly pictureable.

## Run it

```sh
node main.ts
```
